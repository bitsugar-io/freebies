Freeway

Every deal is an overhead freeway sign. Caltrans green, reflective-yellow exit tabs, and Overpass, a free cut of the Highway Gothic typeface used on real signs. Everyone in LA reads these signs every day.

#00653F sign
#F3C300 exit tab
#E7EAE4 concrete
#1D1D1B asphalt
#3B4540 in-venue
Type: Overpass 600/800/900
Effort: M
Dark mode: signs already work on dark

Pros and cons

Works
  • Unmistakably LA, with no team marks
  • Signs make the hierarchy obvious: deal, team, how to claim
  • The icon writes itself: a green sign with a yellow tab
Watch
  • Lots of green can look like a transit or government app
  • Shield badges need care so they don't read as team logos
What changes in the code
  1. src/hooks/useTheme.tsx: replace the Material palette with tokens sign, signInk, tab, ground, asphalt, muted; dark mode swaps ground to asphalt and keeps the signs.
  2. Add expo-font with Overpass and a typography scale token (none exists today; about 48 inline font sizes to move over).
  3. New SignCard component replaces ActiveDealCard: 2px white inner border, optional exit tab for counts.
  4. RouteShield component for team rows: clip-path shape, team short code, no team color.
  5. App.tsx: tabs become Tonight, Deals, Teams, You with line icons (@expo/vector-icons Feather or SF Symbols through expo-symbols).
  6. New TonightBlock in components/blocks/, registered in BlockRenderer and served from /config.
  7. Icon: green rounded square, yellow tab top-right, white "LA". Splash in the same palette; update app.json colors.

Golden hour

The sky over the 10 at 4:45pm: plum into coral into gold, with palm silhouettes. A warm editorial serif makes it feel like a lifestyle app rather than a coupon app.

#2B1B4A dusk
#8D3B6B haze
#F2784B coral
#FBC26B gold
#1C1430 night
Type: DM Serif Display + Manrope
Effort: M
Dark mode: dark-first; light variant needs separate design

Pros and cons

Works
  • The prettiest of the ten; makes great App Store screenshots
  • Friendly copy ("Two things are free today") fits the tone
Watch
  • Sunset gradients and palms are the obvious LA cliché
  • Less clear at a glance during a game
  • The sky gradient is the only gradient; resist adding more
What changes in the code
  1. useTheme.tsx: dark-first token set; light mode becomes a "daytime" sky (pale gold to white).
  2. expo-linear-gradient used only on the home header; one SkyHeader component.
  3. Palm silhouette as a single SVG via react-native-svg (already an Expo-supported package).
  4. Fonts: DM Serif Display for headings and deal names, Manrope for body.
  5. Headline copy written by the server ("Two things are free today"), so it can change without a release.
  6. Icon: gold sun half-set behind a plum horizon.

Jumbotron

The arena scoreboard: amber LED dot-matrix on black, live score on top, and a progress bar for "how close is my free food". Made for the second screen during the game.

#050505 board
#FFB000 LED
#FF3B30 live
#3DFF7A unlocked
#9A6A00 dim
Type: Doto (LED) for numbers and labels
Effort: M (UI) + L (live data)
Dark mode: dark only

Pros and cons

Works
  • Pairs exactly with live alerts and Live Activities
  • The progress meter ("72% there") is a hook no competitor has
Watch
  • Needs live in-game data to be honest; the paid-feed decision comes first
  • All-caps dot-matrix text is tiring outside of game time
  • Dark-only conflicts with the app's light-mode support
What changes in the code
  1. Backend first: a live poller and a GET /live endpoint (option 4 on the options page). Without it this is a costume.
  2. Scoreboard component with a DealMeter: progress = how close the current game state is to the trigger (e.g. goals/5, or win probability for "win" rules).
  3. Doto for scores only; keep a readable sans for body text to fix the all-caps fatigue.
  4. Force dark: userInterfaceStyle: "dark" in app.json, or keep light mode as a "day game" variant.
  5. Polling at 20s while a followed game is live, with AppState pausing in the background.

Metro lines

The LA Metro map: each team you follow is a colored line, games are stops, and deals are stations you've reached. Clean, white, systematic, and it scales to fifteen teams without clutter.

#FFFFFF
#111111 ink
#F47A20 line
#6B4FA0 line
#0072BC line
Type: Public Sans
Effort: S–M
Dark mode: easy; lines pop on dark

Pros and cons

Works
  • Most scalable layout: a season reads as a timeline
  • Following a team = "adding a line" is an intuitive model
  • Easiest to build and the most accessible
Watch
  • Line colors drift toward team colors; assign from a neutral set, not each team's
  • Metro mostly sells to people who already ride it
What changes in the code
  1. Tokens: neutral base plus a categorical palette of 8 line colors assigned per team in the API (not team brand colors).
  2. TeamLine component: vertical bar, bullet with short code, stop rows; FlatList of lines.
  3. Rename Teams tab to Lines; "Add a line" replaces the Discover screen's subscribe flow.
  4. Needs the teams table and a next-game field per team (schedule endpoint).
  5. Icon: three colored lines crossing at a white station dot.

Thomas Guide

The spiral-bound street atlas every LA car had in the glovebox: yellow cover, grid-lettered map pages, freeways in orange. Venues are pins; deals have a grid reference. Nostalgic for Angelenos over 30, and new to everyone else.

#F5C400 cover
#F3EED8 map
#E85D04 freeway
#D62828 pin
#1F1F1F ink
Type: Libre Franklin 400–900
Effort: M–L (map)
Dark mode: "night map": dark paper, same freeways

Pros and cons

Works
  • The most original idea here; very local
  • A map is useful for in-venue and "near me" deals
Watch
  • Most deals are claimed in an app, not at a location, so the map is half decoration
  • A real map component adds weight and work
  • The paper tone sits near the overused "cream" look; keep it map-tinted, not beige
What changes in the code
  1. Start with a static stylized SVG map of the basin (8 venues), not a live map SDK.
  2. GridRef badge: computed from venue lat/lng over a fixed grid, stored on the teams/venues table.
  3. Later: react-native-maps with a custom style JSON in the same palette for location-based deals.
  4. Icon: yellow cover with a black spiral edge and a red pin.

Native clean

No costume: iOS grouped lists, system type, large titles, one jacaranda-purple accent (the trees that bloom over LA every May). It looks like it shipped with the phone, and lets widgets and Live Activities feel at home.

#F2F2F7 grouped
#FFFFFF cell
#8E6CC0 jacaranda
#000000 label
#6E6E73 secondary
Type: SF Pro (system)
Effort: S
Dark mode: free with system colors

Pros and cons

Works
  • Least effort, most accessible, ages well
  • Closest to Apple's guidelines; easy App Review
  • Best base for option 9 (widgets, Live Activities)
Watch
  • The only "LA" is a purple accent; the icon and screenshots must carry the brand
  • Looks like many other apps
What changes in the code
  1. useTheme.tsx: map tokens to iOS system colors (PlatformColor('systemGroupedBackground') etc.) with Android Material 3 equivalents.
  2. Consider @expo/ui (SwiftUI-backed components in SDK 58) for lists and buttons; the Expo expo-ui skill covers it.
  3. Native large-title headers via React Navigation headerLargeTitle.
  4. Remove all hardcoded hex values; nothing custom except the accent.
  5. Icon carries the brand: jacaranda blossom on deep purple.

How to choose: pick the look that matches who you're building for. Watching the game: Jumbotron. Casual fans: Golden hour or Venice. All of LA, with personality and room to grow: Freeway or Metro. Lowest effort: Native clean. You can also mix: Native clean's structure with Freeway's signs for the deal cards is a strong combination.
